# COMP1238 - My Study Notes

## Week 1 - History
- Writing systems were created to record and share information.
- Cuneiform was one of the earliest writing systems.
- The Epic of Gilgamesh is an example of ancient literature.

## Week 2 - Bits and Bytes
- A bit is the smallest unit of digital information and has a value of 0 or 1.
- One byte is equal to 8 bits.
- Computers use binary numbers to store and process data.

## Week 3 - Text and Characters
- ASCII is used to represent characters in computers.
- Unicode supports letters and symbols from many languages.
- UTF-8 is a common character encoding used on websites.

## Week 4 - Files and Directories
- Files store information, and directories help organize files.
- File extensions such as .txt and .md indicate different file types.
- An absolute path shows the full location of a file.

## Week 5 - Command Line and Git
- The command line lets us control a computer using text commands.
- The ls command lists files and directories, and cd changes directories.
- Git tracks changes to files, while GitHub stores repositories online.
